# Pintwist Memory

## Purpose

This folder is the local memory home for Pintwist.

Keep here:
- app-specific operational notes
- Pinterest extension decisions
- app-local architecture notes
- future recurring defects for Pintwist

## Rules

- Keep shared workspace notes out of this folder unless they are truly app-specific here.
- Keep Pintwist detail adjacent to this app.
- If a note is temporary and still belongs to this app, use `cabinet/` until it is promoted, moved, or deleted.
